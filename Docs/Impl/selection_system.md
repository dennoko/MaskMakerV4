# UV Mask Maker 機能仕様書 - 選択システムとピッキング (Selection System & Picking)

## 1. 概要

本モジュールは、三角形単位の選択状態に対する操作（スマートトグル、なぞり選択、パーツ一括選択、全選択・反転、拡張/縮小、左右対称）と、SceneView・UV ビューからのピッキングを規定します。

---

## 2. 選択状態のデータモデル

選択状態は**三角形ごとのビット列**として `EditState.SelectedBits`（[overview.md](overview.md) §5.4）に保持します。

```csharp
int[] SelectedBits;   // 長さ ceil(T / 32)。三角形 t は SelectedBits[t >> 5] の bit (t & 31)
```

- **選択の単位は選択状態に含まれない**。選択の単位（`Granularity`）は「次の操作で扱うまとまり」を決めるだけで、切り替えても選択ビットは変わらない。旧仕様の `ConvertSelection`（全包含ルールによる変換）は廃止。
- **有効三角形**: 対象サブメッシュ（`TargetSubmesh`、-1 は全体）に属する三角形。ピッキング・全選択・反転・選択数の表示は有効三角形だけを対象にする。サブメッシュを切り替えても、他のサブメッシュの選択ビットは保持される。
- ビット列は 10 万三角形で約 12.5KB。履歴・保存には丸ごとコピーで足りる。

### 2.1 グループの選択状態
現在の粒度のグループ $g$ について、属する三角形のビットを数えて 3 状態を求めます（グループの三角形数に比例。ホバー対象が変わった時とクリック時にだけ計算）。

| 状態 | 条件 |
| :--- | :--- |
| **Full** | グループの全三角形が選択済み |
| **Partial** | 一部だけ選択済み |
| **None** | どれも選択されていない |

### 2.2 選択数の表示
カプセルの `12/480` は「現在の粒度で Full のグループ数 / 有効三角形を含むグループ数」です。選択または粒度が変わった時だけ再計算します（$O(T)$）。

---

## 3. 履歴

選択を変える操作は、いずれも統合履歴に 1 件として積みます（[mask_processing.md](mask_processing.md) §3）。ドラッグ中の連続変更はマウスを離すまでで 1 件です。

---

## 4. 選択操作

### 4.1 操作一覧

| 操作 | 入力 | 動作 |
| :--- | :--- | :--- |
| **スマートトグル** | クリック | 指したグループが Full なら除外、Partial / None なら追加（グループ全体）。 |
| **強制追加 / 強制除外** | Shift / Ctrl + クリック | グループの状態に関わらず追加 / 除外。 |
| **なぞり選択** | 左ドラッグ | ドラッグ開始時のグループの状態から追加か除外かを決め（トグルと同じ規則。Shift / Ctrl があればそれに従う）、通過したグループすべてに同じ操作を適用。 |
| **パーツ一括選択** | ダブルクリック | 1 回目のクリックの結果を取り消し（履歴にも残さない）、指した三角形の **ConnectedMesh** グループに対してトグル規則を適用。現在の粒度には依存しない。 |
| **全選択** | Ctrl+A | 有効三角形をすべて選択。 |
| **反転** | Ctrl+I | 有効三角形のビットを反転。他のサブメッシュのビットは変えない。 |
| **クリア** | ラジアル / カプセル | 選択ビットと手塗りレイヤーを同時に全消去（統合クリア、[mask_processing.md](mask_processing.md) §3.3）。 |
| **拡張 / 縮小** | Shift + ホイール | §4.4 |

すべての操作は、適用対象を「現在の粒度のグループ全体」に広げてからビット列を書き換えます。操作の単位はビット列のワード（32 三角形）で処理でき、全選択・反転は $O(T/32)$ です。

### 4.2 なぞり選択の通過判定
マウス移動ごとにピッキング（§5 / §6）を行い、前回と違うグループに入ったらそのグループに操作を適用します。同じグループに 2 度入っても結果は変わりません（追加 / 除外は冪等）。

### 4.3 ダブルクリックの履歴
1 回目のクリックで積んだ履歴を、2 回目のクリックの時点で取り消して（Redo にも残さない）、パーツ一括選択を 1 件として積み直します。

### 4.4 拡張 / 縮小（Grow / Shrink）
三角形隣接（[mesh_analysis.md](mesh_analysis.md) §5.2）を使い、現在の粒度のグループ単位で 1 段ずつ広げる / 狭めます。

- **拡張**: 選択済み三角形に隣接する未選択の有効三角形を集め、それらを含むグループ全体を追加する。
- **縮小**: 未選択（または無効）の三角形に隣接する選択済み三角形を集め、それらを含むグループ全体を除外する。
- ホイール 1 目盛りで 1 段、1 段ごとに履歴 1 件。
- ConnectedMesh は定義上隣接するグループを持たない（位置を共有すれば同じグループになる）ため、拡張しても変化しない。

### 4.5 左右対称（X-Mirror）
対称が ON の時、選択操作は対称位置のグループにも同じ結果（追加なら追加、除外なら除外）を適用します。

1. 操作対象のグループ $g$ の全三角形について `MirrorTri[t]`（[mesh_analysis.md](mesh_analysis.md) §8）を引き、その三角形が属する（現在の粒度の）グループに投票する。
2. 最多得票のグループ $g'$ を対称グループとする。得票が $g$ の三角形数の半分未満なら対称グループ無しとし、$g$ だけに適用する。
3. $g' = g$（体の中心にまたがる島など）なら $g$ だけに適用する。
4. 追加か除外かは、クリックした側のグループの状態だけで決め、対称側にも同じ操作を適用する（両側の状態が食い違っていても揃う）。
5. ホバー中は $g'$ も同時に縁取りする。

## 5. 3Dピッキング（SceneView）

SceneView でカーソル下の三角形を特定します。シーンに一時オブジェクトを作らず、CPU 上で作業メッシュに直接レイを当てます（旧仕様の一時 `MeshCollider` と `Physics.Raycast` は、他のコライダーに遮られる・レイヤーに依存する・シーンに一時オブジェクトが残り得るため廃止）。

### 5.1 手順
1. `HandleUtility.GUIPointToWorldRay(mousePosition)` でワールド空間のレイを作る。
2. 対象 Renderer の `worldToLocalMatrix` でレイを作業メッシュのローカル空間へ変換する（作業メッシュの頂点はローカル空間で保持、[work_context_and_rendering.md](work_context_and_rendering.md) §2.4）。
3. 有効三角形すべてに Möller–Trumbore 交差判定を行い、シーンに描かれる面の中で最も近い交点を採用する。
   - **カリング**: サブメッシュのマテリアルの `_Cull` / `_CullMode`（`UnityEngine.Rendering.CullMode`）に従い、描かれない面には当たらない。プロパティが無いマテリアルは Back（裏面に当たらない）。値は作業開始時に読む。判定はローカル空間で行うので、負のスケールでも Unity の描画と同じ面が残る。
   - **表の優先**: 両面のマテリアルで表と裏がほぼ同じ距離にある時（表地と裏地が重なった衣装など）、表を採用する（裏面の距離を 0.01% 割り増して比べる）。
   - **共有辺のすり抜け防止**: 重心座標に 1e-5 の許容幅を持たせ、隣り合う三角形の辺や頂点の上でレイがどちらにも当たらず奥へ抜けることを防ぐ。
   - オーバーレイは両面表示のまま（X-Ray で奥の面を見せるため）。
4. 結果: 三角形番号、交点（ワールド座標）、交点の法線。グループは現在の粒度の `TriToGroup` で引く。

10 万三角形で 1 回数 ms を想定しています。ホバーはマウス移動ごとに 1 回だけ実行します。不足した場合は BVH を追加しますが、呼び出し側のインターフェースは変えません。

### 5.2 ピッキングの一時停止
- 一時停止中（`ScenePickPaused = true`、Space 押下中、または Unity の他のツールを選んだ時）は、ピッキングとクリックイベントの消費を行わない。
- オーバーレイとシーム線の描画は続け、Unity 標準の Transform 操作やシーン選択を使えるようにする。

## 6. 2Dピッキング（UV ビュー）

UV ビューでカーソル下の三角形を特定します。旧仕様のラベルマップ（解像度分の `int[]` に後から描いた三角形だけが残る方式）は、UV が重なった部分の下側を選べず、1px 未満の三角形も選べないため廃止します。

### 6.1 UV グリッド
- 補正後 UV（`TriUV`）の 0〜1 を 128×128 のセルに分け、各三角形をその外接矩形が重なるセルすべてに登録する（CSR 形式）。解析時に 1 回だけ作る。
- 問い合わせ: カーソルの UV $p$ を含むセルの三角形について、重心座標で内外判定する。`NeedsWrap` の時は $p \pm 1$ の 8 点も調べる。
- 判定は幾何的に厳密なので、表示上 1px 未満の三角形でもカーソルがその中にあれば当たる。

### 6.2 重なった UV
同じ UV 領域を複数の三角形が共有している場合（左右で UV を共有するアバターなど）、その領域はテクスチャ上で区別できず、どちらを選んでも同じテクセルが塗られます。そのため UV ビューでの操作は、**カーソル下の全三角形のグループすべて**に同じ操作を適用します。トグルの判定は「全グループが Full なら除外、それ以外は追加」です。
