# UV Mask Maker V4 ユーザーマニュアル

本書は、Unity エディタ上で 3D モデルに対するマスクテクスチャの作成・編集・適用を行う拡張ツール「**UV Mask Maker V4**」の操作マニュアルです。本ツールの基本機能、操作手順、および各種設定項目について説明します。

---

## 1. ツール概要

### 1.1 概要と目的
**UV Mask Maker V4** は、Unity の SceneView 上で 3D メッシュ（VRChat 向けアバターや衣装など）に対して直接ポリゴン選択や手塗りペイントを行い、白黒マスクテクスチャを生成・適用するためのエディタ拡張機能です。

外部のペイントソフトウェア（Photoshop、CLIP STUDIO PAINT 等）と Unity の間を行き来することなく、SceneView 上でリアルタイムに見た目を確認しながら、マスクテクスチャの生成からマテリアルへの割り当てまでを一貫して実行できます。

### 1.2 動作環境・前提条件
- **対応環境**: Unity 2022.3 LTS 以降
- **対象オブジェクト**: `SkinnedMeshRenderer` または `MeshRenderer` コンポーネントを保持する GameObject
- **推奨シェーダー**: lilToon、Poiyomi Toon Shader、Sunao Shader 等、マスクテクスチャ入力スロットを有する主要シェーダー
- **メッシュ要件**: 作業対象のメッシュに適切な UV 展開（UV0）が行われていること

## 2. 画面構成と各部名称

本ツールは、作業効率を最大化するために以下の画面要素で構成されています。

```
+-------------------------------------------------------------------+
| メインウィンドウ (EditorWindow / ツールタブ)                      |
| [対象オブジェクト指定] [作業開始/終了]                             |
| +---------------------------------------------------------------+ |
| | UV ビュー (2D UV 展開図プレビュー / ピッキング / ペイント)    | |
| +---------------------------------------------------------------+ |
| [出力設定: ファイル名 / 解像度 / チャンネル / 詳細設定]          |
| [出力ボタン (Ctrl+Enter)]                                         |
+-------------------------------------------------------------------+

SceneView 上:
  - シーンビューツールバー (画面内を自由に移動可能なフローティングバー)
  - ラジアルメニュー (C キー長押しでカーソル直下に展開)
  - 通知パネル (出力完了時等に画面上へトースト表示)
```

### 2.1 メインウィンドウ（ツールタブ）
Unity 上部メニューの **`dennokoworks` > `MaskMaker V4`** から開きます。
- **対象オブジェクト指定**: 作業対象の Renderer を指定し、編集の開始・終了を行います。
- **UV ビュー**: 展開された 2D UV マップ上で直接選択やペイント作業を行います。
- **出力設定**: 生成するテクスチャのファイル名、解像度、チャンネル書き込み、余白拡張などを設定します。
- **言語切り替え**: ヘッダー右上の `JA` / `EN` ボタンにより、表示言語を切り替えます。

### 2.2 シーンビューツールバー
編集開始時に SceneView 内に表示されるフローティングバーです。バーをドラッグして画面内の任意の位置へ配置できます。
- **モード切り替え**: 選択モードとペイントモードを切り替えます。
- **選択単位**: 島（Island）、パーツ（Part）、面（Face）の 3 段階を切り替えます。
- **ペイントツール**: ブラシ、矩形、投げ縄、消しゴムを選択します。
- **補助機能**: 左右対称編集（X-Mirror）、対象の孤立表示、X-Ray（透過）表示の有効/無効を切り替えます。
- **履歴・出力**: 取り消し（Undo）、やり直し（Redo）、選択解除、クイック出力を実行します。

### 2.3 ラジアルメニュー
SceneView 上で **`C` キーを長押し** している間、カーソル直下に円形メニューが表示されます。キーを押したまま任意のツールの方向へマウスを移動し、キーを離すことで、視線やカーソルを大きく動かすことなく素早くツールを切り替えられます。

### 2.4 通知パネル（トーストUI）
テクスチャの出力完了時などに画面上へ一時表示される通知メッセージです。出力完了トースト内の **`適用`** ボタンをクリックすることで、マテリアルの適切なテクスチャスロットへ即座に自動割り当てが行われます。

## 3. 基本操作手順（クイックスタート）

オブジェクトの一部を選択してマスク画像を生成し、マテリアルへ適用するまでの標準的な手順は以下のとおりです。

```
[Hierarchy で選択] → [右クリックで開始] → [メッシュをクリック選択] → [Ctrl+Enter で出力] → [適用 をクリック]
```

### 手順 1: 作業の開始
1. Hierarchy 上でマスクを作成したいオブジェクト（衣装やアバターのメッシュ）を選択します。
2. オブジェクトを右クリックし、コンテキストメニューから **`dennokoworks` > `MaskMaker V4`** を選択します。
   ※メインウィンドウの「作業開始」ボタンをクリックすることでも開始できます。
3. 作業対象のメッシュ以外が自動的に非表示（孤立表示）となり、カメラが対象へフォーカスします。

### 手順 2: マスク範囲の指定
1. SceneView 上で、マスクしたい部分を **左クリック** します。
   - 未選択の箇所をクリックすると選択に追加され、選択済みの箇所をクリックすると選択から除外されます。
   - 連続したパーツ全体を選択したい場合は、対象箇所を **ダブルクリック** します。
2. 腕や靴など左右対称の構造を持つメッシュの場合は、**`X` キー** を押して左右対称編集を有効にすることで、片側を選択するだけで反対側も同時に選択されます。

### 手順 3: テクスチャ出力とマテリアル適用
1. **`Ctrl + Enter`** キーを押します（メインウィンドウまたはツールバーの出力ボタンを押すことでも同様に実行できます）。
2. 出力が完了すると、画面上に完了通知（トーストUI）が表示されます。
3. 通知内の **`適用`** ボタンをクリックします。マテリアル設定が自動解析され、シェーダーのマスク用テクスチャスロットに画像が割り当てられます。
   ※該当するスロット候補が複数存在する場合は選択リストが表示されますので、目的のスロットをクリックしてください。

## 5. 機能詳細

### 5.1 選択機能（Selection Mode）

メッシュのポリゴン構造に基づいてマスク領域を指定します。**`Tab` キー** を押すことで、ペイントモードと相互に切り替えることができます。

#### 選択単位（粒度）の切り替え
数字キーの **`1` / `2` / `3`**、またはツールバー／ラジアルメニューから切り替えます。
- **1: 島（Island）**: UV 展開図の切れ目（シーム）で区切られた領域単位で選択します。衣装の布地パーツなどを大まかに指定する場合に適しています。
- **2: パーツ（Part）**: 幾何学的に頂点が結合しているメッシュの塊全体を選択します。メッシュ上のダブルクリック操作でも同様に選択可能です。
- **3: 面（Face）**: 三角形ポリゴン 1 枚単位で選択します。島やパーツ内の一部分のみを微細に除外・追加する場合に使用します。

※選択単位を切り替えても、これまでに選択した状態は保持されます。

#### 選択操作の仕様
- **追加と除外（スマートトグル）**: 未選択箇所をクリックすると選択に追加され、選択済み箇所をクリックすると選択から除外されます。
- **ドラッグによる連続選択**: 左マウスボタンを押したままドラッグしてカーソルを通過させることで、なぞった領域を連続して選択または除外できます。
- **修飾キーによる強制指定**:
  - `Shift` + クリック / ドラッグ: 対象箇所を常に「選択に追加」します。
  - `Ctrl` + クリック / ドラッグ: 対象箇所を常に「選択から除外」します。
- **選択範囲の拡張・縮小**:
  - `Shift` + マウスホイール上回転: 現在の選択範囲を、隣接するポリゴンへ外側へ 1 段階拡張します。
  - `Shift` + マウスホイール下回転: 現在の選択範囲を内側へ 1 段階縮小します。
- **左右対称編集（X-Mirror）**:
  - `X` キーを押すことで有効/無効を切り替えます。
  - アバターの X 軸中心を挟んで反対側にある対応ポリゴン・パーツが自動判定され、左右同時に選択・除外されます。

---

### 5.2 ペイント機能（Paint Mode）

ポリゴン境界にとらわれず、フリーハンドで柔軟にマスクを描き込むモードです。**`Tab` キー** で選択モードから切り替えます。

#### ペイントツールの種類
ラジアルメニュー（`C` キー長押し）または対応ショートカットキーで切り替えます。
- **ブラシ (`B`)**: 3D メッシュ表面に沿って円形ブラシで直接マスクを塗り込みます。
- **矩形塗りつぶし (`M`)**: 画面上でドラッグした矩形領域内を一度に塗りつぶします。
- **投げ縄塗りつぶし (`L`)**: フリーハンドで囲んだ任意の形状の内側を一括で塗りつぶします。
- **消しゴム (`Shift + B`)**: ペイントした塗りを消去します。

#### ブラシサイズの調整
- **`Ctrl` + 右ドラッグ**: メッシュ上で左右にマウスをドラッグすることで、カーソル位置のブラシ半径を視覚的に確認しながら連続調整できます。
- **`[` キー / `]` キー**: `[` でブラシサイズを縮小、`]` で拡大します。

#### 一時消しゴム機能
どのペイントツールを選択している場合でも、**`Ctrl` キーを押しながらペイント操作を行うと一時的に消しゴムとして機能** します。キーを離すと直前のツールに戻ります。

---

### 5.3 UV ビュー機能

メインウィンドウ中央の UV ビューでは、展開された 2D UV マップ上で直接確認・作業を行うことができます。

- **3D 画面との共通操作**: SceneView と同様のツールおよびショートカットキーを使用して、UV ビュー上でもクリック選択やブラシペイントが可能です。
- **ビューの操作方法**:
  - マウスホイール: ビューの拡大・縮小
  - 中ボタンドラッグ（または Alt + 左ドラッグ）: 表示位置の移動（パン）
  - 右上のフォーカスボタン、または `F` キー: 表示倍率と位置を全体表示にリセット
- **ベーステクスチャの重畳表示**:
  - UV ビュー右上のテクスチャアイコンをクリックすると、モデルに設定されている元テクスチャが背景に表示され、テクスチャの柄に合わせた正確な作業が可能です。
- **既存マスク画像の取り込み**:
  - 白黒の画像ファイルを UV ビュー内へ **ドラッグ＆ドロップ** することで、黒い描画部分を手塗りレイヤーへ直接取り込むことができます。

---

### 5.4 出力およびマテリアル適用機能

メインウィンドウの出力カード、または **`Ctrl + Enter`** キーにより、マスクテクスチャを画像ファイルとして出力します。

#### 出力設定項目
- **ファイル名**: 既定では `{Renderer名}_mask.png` が自動設定されます。
- **解像度**: 512 / 1024 / 2048 / 4096 から選択します。
- **チャンネル書き込み**:
  - 単体の白黒テクスチャとして出力するほか、既存テクスチャの特定チャンネル（R / G / B / A）にマスクを合成して書き出すことができます。
- **詳細設定**:
  - **反転**: 白黒を反転したマスクを出力します。
  - **余白拡張（Padding）**: UV アイランドの境界外側へ指定ピクセル数だけ色を塗り広げて出力します。これにより、ミップマップ生成時や遠景表示時のシーム境界の滲み破綻を防止します。
  - **反転も同時保存**: 通常マスクと反転マスクを 2 種類のファイルとして同時に出力します。

#### マテリアルへの適用と更新
- 同一オブジェクトに対する再出力時は前回のファイルへ自動的に上書き保存されます。一度マテリアルに割り当てた後は、再出力を行うだけでマテリアルの表示が自動的に最新状態へ更新されます。
- 出力直後に表示される通知トーストの **`適用`** ボタンをクリックすると、マテリアルのプロパティを解析し、適切なマスク用テクスチャスロットへ自動割り当てを行います。

---

### 5.5 UV 展開図出力機能（UV Wireframe Export）

外部のペイントソフトウェアでテクスチャを作成・加工する際の下絵として利用できる、UV ワイヤーフレーム画像を出力できます。

1. メインウィンドウの UV ビュー右上にある **カメラアイコンボタン** をクリックします。
2. 「UV 展開図の書き出し」設定ウィンドウが表示されます。
3. 以下の出力パラメータを調整します。
   - **解像度**: 512 〜 4096 から選択
   - **描画要素**: ポリゴン線、シーム線、選択ポリゴン限定、アイランド別色分けの有効/無効
   - **背景**: 透過背景、またはベーステクスチャ重畳
   - **カラー設定**: 各要素の線色および塗り色の指定
4. **`書き出し`** ボタンをクリックすると、指定したプロジェクト内のフォルダへ PNG 画像として保存されます。

| **`Ctrl + I`** | 選択操作 | 選択状態を反転 |
| **`Ctrl + Z`** | 履歴 | 直前の操作を取り消し（Undo） |
| **`Ctrl + Y`** | 履歴 | 取り消した操作をやり直し（Redo） |

## 7. 注意事項・トラブルシューティング

### よくある質問と対処法

#### Q. 出力したマスクを適用しても、モデルの見た目が変化しません。
- **A.** 以下の点をご確認ください。
  1. マテリアル側でマスクテクスチャを使用する機能（例: lilToon の「衣装マスク」「描画オフ」「リムライトマスク」等）が有効化されているか確認してください。
  2. マテリアルが複数割り当てられているメッシュの場合、マスクを適用したマテリアルが目的のスロットと一致しているか確認してください。
  3. テクスチャのインポート設定で `Alpha Source` や `sRGB (Color Texture)` の設定がシェーダーの要件と一致しているか確認してください（本ツールからの自動割り当て時は推奨設定が自動適用されます）。

#### Q. 境界部分（シーム）の周辺に意図しない黒や白の隙間（滲み）が発生します。
- **A.** テクスチャの縮小表示（ミップマップ）によって境界色と背景色が混ざり合っている可能性があります。メインウィンドウの出力設定内にある **「詳細設定 > 余白」** の数値を増やして（例: 8 〜 16 px）再出力してください。UV アイランド境界の外側へ同色が塗り広げられ、滲みが解消されます。

#### Q. 左右対称編集（X キー）を押しても反対側が選択されません。
- **A.** 以下の要因が考えられます。
  1. 左右対称編集は、メッシュのローカル X 軸中心（X = 0）を基準に対称な頂点・ポリゴンを検出します。モデルの原点が左右の中心からずれている場合、対称箇所が正しく検出されないことがあります。
  2. メッシュの構造が左右非対称（左右でトポロジーや UV 配置が異なる）なパーツには対称編集が適用されません。その場合は対称編集を OFF にして個別に選択してください。

#### Q. 作業途中で Unity を閉じてしまったり、スクリプトコンパイルが発生した場合はどうなりますか？
- **A.** 本ツールは編集状態（選択状態および手塗りバッファ）を自動的に保存しています。Unity を再起動した場合やコンパイルが走った場合でも、再度同一のオブジェクトを対象にしてツールを開始することで、直前の作業状態から中断することなく作業を再開できます。

#### Q. 操作を誤って全選択解除してしまいました。戻すことはできますか？
- **A.** **`Ctrl + Z`** を押すことで直前の状態に戻すことができます。選択の追加・解除、手塗りのストローク、全解除（Clear）などの全操作は統一された Undo 履歴として管理されています。
