# UV Mask Maker V4 ユーザーマニュアル (日本語版)

Unity エディタ上で 3D モデルに対して直感的にマスクテクスチャを作成・編集・適用できるツール **UV Mask Maker V4** の操作マニュアルです。

---

## 1. ツール概要

**UV Mask Maker V4** は、VRChat 向けのアバターや衣装などの 3D メッシュ（`SkinnedMeshRenderer` / `MeshRenderer`）に対し、Unity の SceneView 上で直接ポリゴンや UV を選択・ペイントして白黒マスク画像を生成・適用できる Unity エディタ拡張ツールです。

外部のペイントソフト（Photoshop, Clip Studio Paint 等）と Unity の間を行き来することなく、Unity 上で見た目を確認しながらわずか数手でマスクを作成・マテリアルへ反映できます。

### 主な特徴

- **ゼロ・トラベル操作系**: マウスを画面端のツールバーへ往復させることなく、カーソル直下のラジアルメニュー（Cキー長押し）や手元ブラシサイズ伸縮（Ctrl+右ドラッグ）で操作が完結します。
- **スマートトグル＆直感選択**: 「追加」「除外」の切り替えボタンは不要。未選択の箇所をクリックすれば追加、選択済みをクリックすれば除外されます。ダブルクリックで服などのパーツ丸ごとを一括選択できます。
- **左右対称編集（X-Mirror）**: アバターの X 軸対称位置を自動判定。腕や足、靴などの選択・ペイントを反対側にも自動同期し、作業手数を半減させます。
- **ワンクリック開始＆自動復元**: 対象を選んで「作業開始」を押すだけで、解析・孤立表示・カメラフォーカス・前回の作業状態の復元まで全自動で行われます。
- **クイック出力＆スマート適用**: `Ctrl + Enter` で即座に出力。完了トーストの「適用」ボタンを押すだけで、lilToon や Poiyomi などのマテリアルのマスクスロットへ自動で割り当てられます。
- **UV展開図（ワイヤーフレーム）出力**: 外部ソフトで詳細テクスチャを描くための下絵用ワイヤーフレーム PNG もワンクリックで書き出せます。

## 2. クイックスタート（最小限の使い方）

もっとも基本的な「衣装の一部を選んでマスクを出力し、マテリアルへ適用する」までの手順です。

```
[Hierarchy で選択] → [右クリックで開始] → [メッシュをクリック選択] → [Ctrl+Enter で出力] → [[適用] クリック]
```

### ステップ 1: 作業を開始する
1. Hierarchy 上でマスクを作りたいオブジェクト（衣装やアバターのメッシュ）を選択します。
2. 右クリックしてメニューから **`dennokoworks` > `MaskMaker V4`** を選択します。
   - （または上部メニュー `dennokoworks` > `MaskMaker V4` からウィンドウを開き、**「作業開始」** ボタンを押します）
3. 作業対象のメッシュだけが自動的に孤立表示され、カメラがフォーカスされます。

### ステップ 2: マスクしたい部分を選択する
1. SceneView 上で、マスクしたい部分を **左クリック** します。
   - クリックした UV アイランド（UV の島）が選択され、マスク表示になります。
   - 選択済みの場所をもう一度クリックすると選択が解除されます。
   - **ダブルクリック** すると、接続されているパーツ全体（例: リボン、靴、ボタンなど）を一括選択できます。
2. 両腕や両袖など左右対称のパーツを扱う場合は、**`X` キー** を押して左右対称（X-Mirror）を ON にすると、片側をクリックするだけで反対側も同時に選択されます。

### ステップ 3: 出力してマテリアルへ適用する
1. キーボードの **`Ctrl + Enter`** を押します（または画面上の「出力」ボタンをクリック）。
2. 出力が完了すると、カーソル脇に **`[SaveAs] (ファイル名).png  [適用]`** のトースト通知が表示されます。
3. トースト内の **`[適用]`** ボタンをクリックします。
   - マテリアルのマスク用テクスチャスロット（例: lilToon の 2nd カラーマスクや Poiyomi のデカールマスク等）に自動で割り当てられます。
   - スロット候補が複数ある場合は一覧が出るので、設定したいスロットをクリックして完了です。

## 4. 詳細詳解

### 4.1 選択モードの詳細とテクニック

選択モード（キーボードの `Tab` でペイントモードと相互切り替え）は、メッシュのポリゴン構造に沿ってマスク範囲を指定する基本モードです。

#### 3 つの選択単位
キーボードの `1` / `2` / `3` キー、またはラジアルメニュー / カプセルツールバーで切り替えます。
- **1: 島（UV アイランド）**（既定）: UV の切れ目で区切られたまとまり単位で選択します。服の布地やパーツごとに大まかに塗るのに最適です。
- **2: パーツ（接続メッシュ）**: 頂点が繋がっているメッシュの塊全体を選択します。ダブルクリックでも同じ動作になります。
- **3: 面（ポリゴン）**: 三角形ポリゴン 1 枚単位で選択します。島の一部分だけを細かく除外したい場合などに便利です。

> [!TIP]
> **選択単位を切り替えても既存の選択は消えません**  
> 「面」で細かく選んだあとに「島」に切り替えても、これまでに選択した面は維持されます。「選択単位」は *次にクリックしたときに扱うまとまりのサイズ* を決めるだけの安全な設計です。

#### マウス操作のコツ
- **スマートトグル**: 未選択の箇所をクリックすると追加され、選択済みの箇所をクリックすると解除されます。
- **なぞり選択（左ドラッグ）**: マウスの左ボタンを押したままドラッグすると、通過したパーツを連続で追加（または解除）できます。
- **強制追加 / 強制除外**:
  - `Shift + クリック / ドラッグ`: すでに選択されているかに関わらず、**必ず「追加」** します。
  - `Ctrl + クリック / ドラッグ`: **必ず「除外」** します。
- **選択の拡張 / 縮小**:
  - `Shift + マウスホイール上`: 選択範囲を周囲の隣接ポリゴンへ 1 ステップ拡張します。
  - `Shift + マウスホイール下`: 選択範囲を 1 ステップ縮小します。

#### 左右対称（X-Mirror）機能
- **`X` キー** でいつでも ON/OFF を切り替えられます。
- 有効時は、アバターの中心（X=0）を挟んで反対側にある対応パーツも自動的にハイライトされ、クリック 1 回で両側が同時に選択されます。
- 腕、脚、手袋、靴、装飾品などの対称パーツを編集する際にカメラを反対側へ回す必要がなくなります。

### 4.2 ペイントモードの詳細とテクニック

`Tab` キーを押すとペイントモードに切り替わります。メッシュのトポロジー（ポリゴンの区切り）にとらわれず、フリーハンドで自由にマスクを描き込みたい場合に使用します。

#### 4 つのツール
ラジアルメニュー（C長押し）またはショートカットで瞬時に持ち替えることができます。
1. **ブラシ (`B`)**: 表面に沿って円形ブラシで直接塗り込みます。
2. **矩形 (`M`)**: ドラッグした画面上の四角形の範囲を一気に塗りつぶします。
3. **投げ縄 (`L`)**: フリーハンドで囲んだ範囲の内側を塗りつぶします。
4. **消しゴム (`Shift + B`)**: 手塗りで塗った部分を消去します。

#### 手元ブラシ伸縮（Ctrl + 右ドラッグ）
- メッシュ上で **`Ctrl` を押しながらマウス右ボタンを左右にドラッグ** すると、カーソル直下のブラシ円の大きさを無段階で調整できます。
- 画面端のスライダーにマウスを持っていく必要がありません。
- キーボードの `[`（小さく）/ `]`（大きく）でも調整可能です。

#### 一時消しゴム
- どのツールを選んでいる時でも、**`Ctrl` キーを押しながら塗ると「消去」** になります。いちいち消しゴムツールに持ち替える必要はありません。

#### 超解像度内部バッファ
- 手塗りの内容は、内部で常に **4096×4096 px** の高解像度で保持されています。
- 出力設定の解像度を 512 や 1024 に下げてプレビューしても、内部の描画データ自体は一切劣化しません。後から解像度を 2048 や 4096 に上げ直せば、元の鮮明なストロークのまま出力できます。

### 4.3 2D UV ビューの活用

ツールタブの中央には **UV ビュー** が配置されています。SceneView 上の 3D モデルだけでなく、展開された 2D UV 上でも直接作業が可能です。

- **操作の共通性**: SceneView とまったく同じツール・ショートカットで、UV ビュー上でもクリック選択やブラシペイントができます。
- **カメラ操作**:
  - マウスホイール: ズームイン / ズームアウト
  - マウス中ボタンドラッグ: 平行移動（パン）
  - 右上のズームアイコンボタン（または `F` キー）: 全体表示（等倍・中央）にリセット
- **ベーステクスチャ重ね合わせ**:
  - UV ビュー右上のテクスチャアイコンをクリックすると、モデルの元テクスチャが背景にうっすら表示されます。絵柄を確認しながらマスクの位置を合わせたいときに便利です。
- **既存マスク画像の取り込み**:
  - 外部で作成した白黒マスク画像や、以前出力したテクスチャファイルを UV ビュー内に **ドラッグ＆ドロップ** すると、黒い部分（マスク領域）を手塗りレイヤーに直接取り込むことができます（Undo にも対応）。

### 4.4 出力設定とマテリアル適用

作業が完了したら、ツールタブの出力カードまたは `Ctrl + Enter` でテクスチャを出力します。

#### 基本出力項目
- **ファイル名**: 既定では `{Renderer名}_mask.png` が自動入力されます。
- **解像度**: `512` / `1024` / `2048` / `4096` から選択します（元テクスチャのサイズが自動で既定値になります）。
- **チャンネル書き込み（オプション）**:
  - チェックを入れると、既存のベーステクスチャ（Base PNG）の特定チャンネル（R / G / B / A）にのみマスクを埋め込んで書き出すことができます。
  - メタリック・スムースネス・AO などの統合テクスチャを作成する際に便利です。

#### 詳細設定（▸ 詳細を展開）
- **反転 (Invert)**: マスクの白黒を反転して出力します。
- **余白 (Pixel Margin)**: マスクの外側へ指定ピクセル数だけ色を広げて出力します（解像度に応じた最適な値が自動設定されます）。ミップマップによる UV 境界の黒ずみ・白滲みを防ぎます。
- **反転も同時保存**: 通常マスク（`_mask.png`）と反転マスク（`_mask_inv.png`）を同時に出力します。

#### 上書き再出力とマテリアル自動適用
- **上書き再出力**: 同じ対象から再出力した場合、余計な連番ファイルを作らず前回のファイルを上書きします。そのため、一度マテリアルにセットしてあれば、Unity 側で自動的に表示が更新されます。
- **スマート適用 ([適用] ボタン)**:
  - 出力直後に表示されるトーストの `[適用]` を押すと、マテリアルの設定を解析し、適切なテクスチャスロット（lilToon や Poiyomi などのマスクプロパティ）へ自動で割り当てます。
  - 初回に対象スロットを選ぶと、その設定がモデルごとに記憶され、次回からは 1 クリックで適用できるようになります。

### 4.5 UV 展開図（ワイヤーフレーム）の書き出し

Clip Studio Paint や Photoshop などのペイントソフトで詳細なテクスチャを描くための下絵として、メッシュのワイヤーフレーム展開図を出力できます。

1. ツールタブの UV ビュー右上にある **`[Camera]` アイコンボタン** をクリックします。
2. 「UV 展開図の書き出し」ウィンドウが表示されます。
3. 設定を調整します：
   - **解像度**: 512 〜 4096（既定 2048）
   - **描画要素**:
     - ポリゴン線（メッシュ内部の三角形エッジ）
     - シーム線（UV の切れ目の外周エッジ）
     - 選択限定（現在選択している部分のみ出力）
     - アイランド着色（UV の島ごとに色分けして塗りつぶし）
   - **背景**: 透過（透明背景）またはベーステクスチャ
   - **線色・塗り色**: シーム線、ポリゴン線、アイランド塗りの色を指定可能
4. **`[書き出し]`** ボタンを押すと、`{ファイル名}_uv.png` としてプロジェクト内に保存されます。

### 4.6 画面 UI とショートカット一覧

#### 画面構成
1. **ツールタブ (EditorWindow)**:
   - 画面上部メニュー `dennokoworks` > `MaskMaker V4` で表示。
   - 対象メッシュの指定、UV ビュー、出力設定、主ボタン（作業開始 / 出力）が集約されています。
   - **ヘッダー**: タイトル、バージョン番号、更新確認ボタン（↻）、**言語切り替えボタン (`[JA]` / `[EN]`)**、および各種設定（Preferences / Project Settings）を開く設定アイコン（⚙）が並んでいます。言語ボタンをクリックすると、開いている全 UI（ツールタブ、カプセルツールバー、UV展開図ウィンドウ等）の表示言語が即座に切り替わります。
2. **手元カプセルツールバー**:
   - 作業開始時に SceneView 内に表示される角丸フローティングバー。ドラッグして画面内の好きな位置へ移動できます。
   - モード切替、選択単位、ペイントツール、X-Mirror、孤立表示、Undo/Redo、出力、選択数表示などがコンパクトに並んでいます。
3. **カーソル直下ラジアルメニュー**:
   - SceneView または UV ビュー上で **`C` キーを長押し** している間、マウスカーソルの真下に円形メニューが現れます。
   - キーを押したまま使いたいツールの方向へわずかにマウスを動かして `C` を離すだけで、ツールを素早く切り替えられます。

| **`1` / `2` / `3`** | 選択単位の切り替え（1: 島 / 2: パーツ / 3: 面） |
| **`B` / `M` / `L` / `Shift+B`** | ペイントツール（B: ブラシ / M: 矩形 / L: 投げ縄 / Shift+B: 消しゴム） |
| **`[` / `]`** | ブラシサイズの縮小 / 拡大 |
| **`C`（長押し）** | カーソル直下ラジアルメニュー表示 |
| **`Space`（長押し）** | ピッキング一時停止（通常のカメラ・移動ツールを操作） |
| **`Ctrl + A`** | メッシュ全体の全選択 |
| **`Ctrl + I`** | 選択範囲の反転 |
| **`Ctrl + Z` / `Ctrl + Y`** | 統合 Undo（元に戻す） / Redo（やり直す） |
| **`Ctrl + Enter`** | クイック出力（現在の設定で即座にテクスチャ生成） |
| **`F`** | UV ビューの表示倍率・位置を初期状態にリセット |
