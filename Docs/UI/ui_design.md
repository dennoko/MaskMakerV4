スタイル/コンポーネント定義: `dennokoworks_color_schema` スキル（UI Toolkit / UXML + USS、ダークテーマ固定、フローティングデザイン）。

## 1. コンセプト

> **「説明書なしで、最短手数で、マウス移動ゼロでマスクが出る」**

| 原則 | 具体策 |
| :--- | :--- |
| **ゼロ・トラベル (Zero Travel)** | マウスを画面端のツールバーへ往復させない。**カーソル直下ラジアルメニュー（C長押し）** と **Ctrl+右ドラッグでの手元ブラシ伸縮** で、手の位置を動かさずに操作完結 |
| **スマート・トグル (Smart Toggle)** | 「追加モード」「除外モード」の切替を廃止。**未選択をクリックで追加、選択済みをクリックで除外**。ダブルクリックでパーツ丸ごと全選択 |
| **左右対称 (X-Mirror)** | VRCアバター特化。**X対称選択（Xキー）** で腕・足・袖・靴などの選択クリック数とカメラ回転を **一律50%カット** |
| **1 クリック開始** | Hierarchy で対象を選ぶ → ツールタブの大ボタン 1 つ（またはシーン上の「Mask Maker で編集」）で作業開始。UV 解析・孤立表示・NDMF 取得・カメラフォーカスは全自動 |
| **状態駆動 UI** | 「未開始 / 作業中 / 出力」の状態に応じて、**今必要な UI だけ**を出す。無関係な設定は見せない |
| **失敗しない** | 全操作が Undo 可能（選択＋手塗り統合履歴）。破壊的操作（クリア）は即実行 + Undo トースト、確認ダイアログは出さない。作業中の選択と手塗りは対象ごとに自動保存し、終了・対象切替・Unity 再起動の後も開き直せば復元される（保存ボタンも「終了しますか？」も無い） |
| **出力〜適用まで最短** | **Ctrl+Enter で一発出力**。出力完了トーストの **[適用]** 1 クリックでマテリアルに割り当て（ドラッグ＆ドロップ不要）。同じ対象の再出力は前回のファイルを上書きするので、適用済みのマテリアルはそのまま更新される（§6.2） |
| **設定の継承 (Inherit)** | 粒度の広い設定（保存先・余白・色・キー）は User → Project → Target と継承し、作業中は見せない。出力ごとに決める項目（名前・解像度・チャンネル）だけを手前に置き、自動推定で初期値を埋める（§2.5） |
| **文字は最後の手段 (Quiet UI)** | 説明文を画面に常設しない。意味は形・状態・値で伝え、文字は「求めた時」と「迷った時」だけ出す。常設の文字は値と最小限の見出しに限る（§2.6） |

## 2. 3 領域の役割分担

```mermaid
graph LR
    A["① ツールタブ<br/>(EditorWindow)<br/>低頻度: 開始/設定/UV/出力"] 
    B["② シーン上の直接操作<br/>(SceneView 入力)<br/>最高頻度: 選択/塗り/トグル"]
    C["③ シーン上フローティングUI<br/>(Overlay & カーソル直下PieMenu)<br/>高頻度: モード/ツール/対称/Undo"]
    A -- 同じ設定を双方向同期 --> C
    C -- 操作の意味を決める --> B
```

| 領域 | 使う場面 | 置く機能 | 置かない機能 |
| :--- | :--- | :--- | :--- |
| **① ツールタブ** | 作業の前後・設定変更 | 対象指定と作業開始/終了、UV/サブメッシュ（対象ごとの設定）、UV プレビュー（2D ピッキング・ペイント兼用）、**テクスチャごとの出力設定（名前・解像度・チャンネル）**、出力サマリ ＋ ▸詳細（プロジェクト既定の確認） | 作業中に何度も切り替えるもの、ユーザー共通の見た目・キー割当（→ 設定アイコンから Preferences） |
| **② シーン直接操作** | 作業の本体 (90%の作業) | スマートクリック（追加/除外トグル）、ダブルクリック（パーツ全選択）、ドラッグ塗り、Ctrl+右ドラッグ（ブラシ伸縮）、Shift+ホイール（選択拡張/縮小）、ホバーハイライト、カメラ保護 | 設定値の変更 |
| **③ フローティング（カプセル・ラジアル・トースト）** | 作業中の切替 (10%の作業) | **カーソル直下ラジアルメニュー (Cキー長押し)**、手元カプセルツールバー（アイコンのみ）、選択の単位、ペイントツール、対称、Undo/Redo/Clear、全選択/反転、一時停止、クイック出力(Ctrl+Enter) | 出力先フォルダや詳細チャンネル設定 |

**設定の単一情報源**: `MaskSettings` を 1 つだけ持ち、①と③は同じ値を参照・即時同期する（片方で変えるともう片方の表示も更新）。

## 2.5 オプション評価とアクセス性ランク（配置の根拠）

全オプションを**使用頻度**と**設定の粒度（スコープ）**の 2 軸で評価し、アクセス性のランクを決めた。
配置ルールは「**頻度が高いほど手元へ、粒度が広いほど奥へ**」。粒度の広い値は一度決めれば継承し、作業中は見せない。

### 2.5.1 評価軸

| 軸 | 段階 |
| :--- | :--- |
| **使用頻度** | ◎ 作業中ずっと（秒〜分単位）／ ○ 出力のたび ／ △ 対象（メッシュ）ごとに 1 回 ／ ▲ プロジェクトで 1 回 ／ ✕ ほぼ触らない |
| **設定の粒度** | **Session**＝作業中の一時状態 ／ **Output**＝テクスチャ（出力物）ごと ／ **Target**＝メッシュ（Renderer）ごと ／ **Project**＝プロジェクト共通 ／ **User**＝全 Unity プロジェクト共通 |

### 2.5.2 ランク定義

| ランク | 到達コスト | 置き場所 | 割り当て基準 |
| :--- | :--- | :--- | :--- |
| **S** | マウス移動 0 | ② 直接操作・ホットキー・ラジアル | 頻度 ◎ |
| **A** | 1 クリック | ③ カプセル・トースト | 頻度 ○ で Session 粒度 |
| **B** | タブを見れば常に見える | ① タブ上段・常時表示 | 頻度 ○〜△ で Output / Target 粒度 |
| **C** | 1 クリックで展開（要約は常時見える） | ① タブの ▸詳細・サマリ行 | 頻度 ▲ で Project 粒度 |
| **D** | 設定ウィンドウを開く | 設定アイコン → Preferences / Project Settings | 頻度 ✕ で User 粒度、または初回のみ |

### 2.5.3 オプション別評価

### 2.5.4 設定の継承と保存

値は上の層から順に解決する（`Session > Target > Project > User > 組み込み既定`）。各層は上書き値だけを持つ。

| 層 | 保存先 | 共有範囲 |
| :--- | :--- | :--- |
| **User** | `EditorPrefs` | 全 Unity プロジェクト共通 |
| **Project** | `ProjectSettings/UVMaskMaker.json` | プロジェクト単位。バージョン管理でチーム共有できる |
| **Target** | `UserSettings/UVMaskMaker/targets/{TargetKey}/settings.json`（キー＝メッシュのアセット GUID と Renderer 名）。作業状態（選択・手塗り）は同じフォルダの `session.bin` | 個人。同じメッシュを開き直すと設定と作業が復元される |
| **Session** | メモリのみ | 作業中のみ |

値が上位の既定と異なる項目には上書きマーク ● を出し、クリックで既定に戻せる。

### 2.5.5 この評価を受けた設計の変更点

1. タブから「選択の単位」と「表示設定」を削除した。前者は S/A として手元に、後者は D として 設定ウィンドウに置いた。
2. 出力カードを基本（B）と ▸詳細（C）に分け、フッター上に出力サマリ行を追加した。詳細を開かなくても出力内容を確認できる。
3. 粒度の広い項目（保存先・余白・反転・色・キー割当・言語）は Project / User に移し、毎回は見せない。
4. ファイル名、解像度、UV、サブメッシュ、Base PNG、X-Mirror の初期値は自動推定にした。
5. サブメッシュ・UV は、選択肢が複数ある時だけ表示する。
6. ホットキーは Unity の Shortcut Manager に登録する。
7. クイック出力は `Ctrl+Enter` に決定（`Ctrl+S` は Unity の「シーン保存」と競合するため不採用）。キーの扱いは §2.6.7。
8. 作業状態（選択・手塗り）は対象ごとに自動保存・自動復元する。これにより終了時の確認ダイアログと保存操作を無くせる。
9. 同じ対象からの再出力は前回のファイルを上書きする。連番はファイル名を変えた時と、他のファイルと衝突した時だけ。調整 → 再出力のくり返しでファイルが増えず、マテリアルの再割り当ても要らない。
10. 選択は三角形単位で保持し、「選択の単位」は次のクリックで扱うまとまりを決めるだけにした。単位を切り替えても既存の選択は消えない。

## 2.6 情報量の設計（文字を増やさずに「説明書なし」を実現する）

「説明書なし」を**画面上の説明文**で実現しようとすると、文字が増えて主導線が埋もれる。
本ツールでは「**説明する**」のではなく「**見れば分かる・触れば分かる・困った時だけ出る**」ことで説明書を不要にする。

### 2.6.1 4 つの原則

1. **形と状態で伝える**: 次に起きることはカーソル形状・ホバーの縁取り色・青枠で示す。文字で「〜できます」とは書かない。
2. **常設の文字は値だけ**: 値を見れば意味が分かる項目（`2048`、`UV1`、`.png`、マテリアル名）にはラベルを付けない。説明文と常設のヒント行は置かない。
3. **説明は求めた時・迷った時だけ**: ツールチップ → 迷いを検知した時の 1 回限りのヒント → キー一覧（§2.6.3）。
4. **メッセージの出口は 1 か所**: タブはステータスバー、シーンはカーソル脇のトーストのみ。同時に出すのは 1 件だけ。優先度は エラー ＞ 警告 ＞ 成功 ＞ 情報。情報と成功は 3〜4 秒で消え、平常時のステータスバーは空にする。

### 2.6.2 文字量の上限（テキスト予算）

| 場所 | 常時表示してよい文字 | 上限 |
| :--- | :--- | :--- |
| カプセル | 選択数の数値のみ（例: `12/480`）。ボタンはアイコンのみ。選択の単位だけは短い語（§2.6.6） | 語は 1 ボタン 3 字まで |
| ラジアルメニュー | ポインタが向いている 1 項目の名前だけを中心に表示 | 8 字 |
| タブの見出し・ラベル | カードの見出しは「出力」のみ。ラベルは値で意味が通らない項目だけ | 1 ラベル 6 字 |
| ステータスバー / トースト | 1 行 | 30 字 |
| 開始バッジ（シーン、Idle のみ） | `Mask Maker で編集 ▶` のみ | 1 行 |
| ドロップ受付表示（UV ビュー） | テクスチャをドラッグしている間だけ `取り込む` | 5 字 |
| 説明文・常設ヒント | なし | 0 |

### 2.6.3 段階的な案内（必要な人にだけ出す）

| 段階 | 出る条件 | 表示 | 頻度 |
| :--- | :--- | :--- | :--- |
| 0 | 慣れた人の通常操作 | 何も出ない | — |
| 1 ツールチップ | アイコンに 0.5 秒ホバー | 名前とキー（例: `ブラシ  B`） | 毎回 |
| 2 修飾キーの予告 | Shift / Ctrl を押している間 | カーソル脇のバッジがアイコンで変わる（`d_Toolbar Plus` / `d_Toolbar Minus`） | 毎回。文字なし |
| 3 迷い検知ヒント | 例: 作業開始後メッシュ上で 3 秒クリックが無い／ペイントで同じ場所を何度も消している／カメラ回転を繰り返している（→ 対称を案内） | カーソル脇に 1 行（例: `クリックで選択`、`X で左右同時`） | 各ヒント 3 回まで。以後は出ない |
| 4 キー一覧 | C を押したまま 0.6 秒マウスを動かさない | ラジアルの各スライスにキーを添え、周囲に主要キーを表示 | 求めた時だけ |

迷い検知ヒントは「その場で必要な 1 つ」だけを出す。チュートリアルや初回ウィザードは作らない。

### 2.6.4 導線を 1 本にする

- **画面ごとに主ボタンは 1 つ**: タブはフッターの主ボタンだけを `.dennoko-button-primary` にし、文言で次の行動を示す（Idle=`作業開始` → Working=`出力`）。他のボタンは副ボタンかアイコンボタン。
- **Idle は 2 要素だけ**: 対象欄と `作業開始`。それ以外は描画しない。
- **同じ機能の出口を役割で分ける**: カプセル＝状態の表示とマウス派の入口、ラジアル＝キーボード派の入口。ラジアルには Ctrl+Z で済む Undo/Redo を入れない。
- **文脈で中身を差し替える**: カプセルの同じ位置を、選択モードでは「選択の単位」、ペイントモードでは「ペイントツール」にする。ラジアルもモードごとに中身を切り替える。表示中の項目数は常に一定。
- **折りたたみの中身は要約で見せる**: 詳細は閉じたまま、サマリ行に値のチップ（アイコン＋値）で出す。文章にしない。

### 2.6.5 用語を固定する

画面・ツールチップ・ヒント・ステータスで同じ語を使い、語彙を増やさない。内部名はコードとこの設計書の中だけで使う。

| 概念（内部名） | 表示名 | 使わない語 |
| :--- | :--- | :--- |
| `UVIsland` | 島 | アイランド、UVアイランド |
| `ConnectedMesh` | パーツ | 接続メッシュ |
| `Polygon` | 面 | ポリゴン、三角形 |
| X-Mirror | 対称 | ミラー、X-Mirror |
| `IsPaintMode` | 選択 / ペイント | 塗りモード |
| Unified Clear | クリア | 全消去、リセット |
| `TargetSubmesh` | マテリアル名をそのまま表示 | サブメッシュ |

### 2.6.6 アイコン（Unity 標準のみ）

- 使えるのは `EditorGUIUtility.IconContent` / `EditorGUIUtility.FindTexture` で取得できる **Unity Editor 内蔵アイコンだけ**。絵文字・独自画像は使わない。
- テーマはダーク固定なので、エディタが Light でも**常に `d_` 付きの版**を読み込む（`d_` 無しの版は暗い色で、Surface0 上で見えなくなる）。

### 2.6.7 ショートカット

- クイック出力は `Ctrl+Enter`。Unity の既定プロファイルでは `Ctrl+Enter` に割り当ては無いはずだが、実機の Edit > Shortcuts で検索して確認する。
- 全てのキーは SceneView のコンテキストに、**作業中だけ登録するタグ**（`ShortcutManager.RegisterTag`）付きで登録する。`X`（ピボット回転の切替）や `E`（回転ツール）など Unity 既定と重なるキーも、作業中だけ本ツールが優先され、作業終了で元に戻る。
- ラジアルの `C` と一時停止の `Space` を同じキーにはしない（以前の「または Space」は削除）。
- **既存の慣習に合わせる**: `B / M / L / E` と `[ ]`（Photoshop）、`Ctrl+Z / Ctrl+Y / Ctrl+A`（Windows・Unity）、`Ctrl+I`（Blender の選択反転）。キーの意味を新しく覚えさせない。
- 作業中に Unity のツール（`W` 移動 / `R` 拡縮 / `T` 矩形など）へ切り替えると自動で一時停止になる（カプセルの一時停止ボタンが青枠）。本ツールのキー（`Tab` / `1`〜`3` / `B` など）か一時停止ボタンで作業に戻る。
- キーは**マウスが SceneView 上にあれば効く**ようにする。作業中はカーソルが SceneView に入った時点でフォーカスを移し、「タブを触った直後に X を押しても効かない」状態を作らない。

## 3. 作業フロー（状態遷移）

状態は **Idle と Working の 2 つだけ**。出力は状態ではなくイベントで、出力後もそのまま編集を続けられる（再出力は同じファイルを上書き）。

```
                       ┌──── 出力 (Ctrl+Enter) → トースト [適用] ────┐
                       ▼                                            │
[Idle 未開始] ──作業開始──▶ [Working 作業中] ─────────────────────────┘
      ▲                         │
      └──── 終了（作業は自動保存）─┘
```

| 状態 | ツールタブ | シーン | フローティング |
| :--- | :--- | :--- | :--- |
| **Idle** | 対象欄＋「作業開始」のみ（他カードは描画しない） | 通常のシーン。Renderer（またはそれを含む親）を選択中なら右上に開始バッジ `Mask Maker で編集 ▶`（ウィンドウが閉じていても出す） | 開始バッジのみ |
| **Working** | 対象カード＋UV ビュー＋出力カード | 対象メッシュを孤立表示＆自動カメラフォーカス、シーム線、マスク投影、ホバーハイライト | カプセル ＋ C キーでラジアル |
| 出力直後（イベント） | タブから出力した時: ステータスバーに `保存: Body_mask.png` | そのまま編集を継続 | シーンから出力した時: カーソル脇トースト `[SaveAs] Body_mask.png [適用]` |

通知はどちらか一方にだけ出す（§2.6.1 原則 4）。出力した場所に出すので、視線を動かさずに結果を確認できる。

**対象の決め方（Idle）**
- 入口は 3 つで、どれも同じ開始処理を呼ぶ: タブの「作業開始」、シーンの開始バッジ、Hierarchy の右クリック `MaskMaker V4 で編集`。ウィンドウはメニュー `dennokoworks/MaskMaker V4` で開く（バッジ・右クリックからはウィンドウも自動で開く）。
- **Renderer を選択中**: 対象欄に自動入力。主ボタン 1 回で開始。
- **複数の Renderer を含む親（アバター・衣装のルート）を選択中**: 対象欄が子 Renderer の一覧（アイコン＋名前）になる。前回作業した Renderer（無ければ頂点数が最大のもの）を既定にして、主ボタンでそのまま開始。他の項目はクリックで即開始。
- 開始バッジから親を対象にした場合は、シーン上でホバーした Renderer を縁取り、クリックしたものを対象にして開始する（タブへマウスを動かさない）。

**自動処理（ユーザーに操作させない）**
- 開始時: Read/Write 自動修復、UV 解析、`IsolateTargetMesh` による孤立表示、NDMF プレビューメッシュ取得、対象オブジェクトへの自動カメラフォーカス（`SceneView.FrameSelected` 相当）、**前回の作業状態（選択・手塗り）の復元**。
- 終了時: **作業状態の自動保存**、`ExitIsolation`、オーバーレイ解除。
- 自動終了: Play モード開始、シーンの切替、スクリプトの再コンパイル、ウィンドウを閉じた時は終了処理を自動で行う（作業は保存）。再コンパイルの後と Play モードから戻った時は、同じ対象で自動的に作業を再開する。孤立表示や一時オブジェクトをシーンに残さない。
- UV チャンネルに UV が無い場合: UV0 へ自動フォールバックし、ステータスバーに警告（黄）を 1 行出すだけ。
- 対象選択が変わった場合: 作業中は無視（切替は対象名のドロップダウンから）。Idle なら自動で対象欄を更新。

### 4.3 カード詳細と UX 判断

| カード | ランク | 内容（MaskSettings） | UX 判断 |
| :--- | :--- | :--- | :--- |
| **対象** | B | 対象 Renderer、`TargetSubmesh`、`UVChannel`、終了ボタン | Idle ではここに大きなドロップ欄（親を選択中は子 Renderer の一覧、§3）。Hierarchy で Renderer を選択中なら自動入力。Working では対象名がドロップダウンになり、同じアバター配下の Renderer へ切り替えられる（現在の作業は自動保存、切替先の前回作業を復元）。**サブメッシュ・UV は複数ある時だけ表示**。選んだ値は対象（Target）ごとに記憶し、次回は選び直し不要。サブメッシュはマテリアルスロット名で表示 |
| **UV プレビュー** | B | 2D ピッキング（UV が重なった所はその全部に効く）、ペイント兼用、`PreviewOverlayBaseTex`、`PreviewOverlayAlpha`、既存マスク取り込み、**UV 展開図出力** | シーンと**同じツール・同じモード**でそのまま操作可能。ホバーで該当グループをハイライト。ホイールでズーム、中ボタンでパン。右上の `[ViewToolZoom]` ボタン（または F キー）で 100% のサイズ・元の位置に戻す。重ねトグル ON の時だけ不透明度スライダーを表示。テクスチャをドロップすると既存マスクとして取り込む（黒い部分を手塗りに加算、Undo 可）。受付の枠と `取り込む` はドラッグ中だけ出す。<br>**UV 展開図の出力 (`[Camera]` ボタン)**: クリックで直下にミニポップアップを展開。解像度（512〜4096、既定 2048）、描画要素（☑ ポリゴン線、☑ シーム線、☐ 選択限定、☐ 色分け）、背景（透過/ベース）、線色（白/黒/シアン）を指定し、`[書き出し]` で `{FileName}_uv.png` を保存。設定は Target/User で自動保存 |

| **出力（▸詳細）** | C | `InvertMask`、`PixelMargin`、`SaveInvertedToo` | 既定で閉。Project 既定の値を使うので毎回は触らない。`SaveInvertedToo` は ON で実ファイル名（`name.png` / `name_inv.png`）を灰色でプレビュー。`PixelMargin` は解像度に応じた推奨値を既定にする |
| **出力サマリ行**（フッター上） | C | 保存先と ▸詳細の値の要約 | 例: `[Folder] Textures  余白2`。カード上に見えている値（ファイル名・解像度）は重複させない。反転・反転同時保存は ON の時だけチップを出す。文章にせず値のチップだけを並べる。チップをクリックすると該当の詳細を開き、保存先チップは Project Settings を開く。値が Project 既定と違う項目には上書きマーク ● を付け、クリックで既定に戻す |
| **設定アイコン（ヘッダー右）** | D | 表示色・シーム・ホットキー・言語・ヒント | ここから Preferences（User）と Project Settings を開く。作業中のタブには置かない |

### 4.4 出力時の挙動
- 押下 → 成功で `.dennoko-status--success` に `保存: Body_mask.png`（ファイル名クリックで Ping）。4 秒で消える。書き出し中の表示は 0.3 秒以上かかった時だけ出す。シーンから出力した時はステータスバーには出さず、トースト（§6.2）だけにする。
- **上書きと連番**: 同じ対象から前回出力したファイルは上書きする。ファイル名を変えた時、または本ツールが出力していない既存ファイルと衝突した時だけ連番にする。元/反転ペアの番号一致は自動で行い、確定したファイル名をそのまま表示する。
- 選択も手塗りも空のとき: 実行は止めず、警告 `選択なし（全白で出力）` を出す。
- 失敗は `.dennoko-status--error` に原因 1 行（例: `書き込みできません`）。

## 5. ② シーン上での直接操作（最高頻度: ゼロ・トラベル操作系）

画面端のボタンを押すためにマウスを往復させる必要をなくし、**3Dメッシュの手元だけで90%の作業を完結させる操作体系**です。

### 5.1 操作マップ

| 入力 | 選択モード | ペイントモード | UX上の短縮効果 |
| :--- | :--- | :--- | :--- |
| **ホバー** | 指したグループを白縁ハイライト（選択済みなら赤縁にして「消去」を予告） | ブラシ円を表面追従投影 / 矩形・投げ縄ガイド | 実行前に結果が分かり誤操作ゼロ |
| **左クリック (スマートトグル)** | **未選択なら追加、選択中なら除外**（トグル操作） | ブラシ: 1点塗り / 消しゴム: 1点消去 | **追加/除外の切替クリックが不要（0クリック化）** |
| **ダブルクリック** | **そのパーツ丸ごとを一括選択**（パーツ全体が選択済みなら一括除外）。1 回目のクリックの結果は取り消し、履歴は 1 件にまとめる | — | 服のパーツ単位の選択が1アクションで完了 |
| **Shift / Ctrl ＋ クリック・ドラッグ** | 強制追加 / 強制除外 | Shift=塗り、Ctrl=消去（現在のツールの形のまま） | 消しゴムへの持ち替えが不要。両モードで「Shift=足す / Ctrl=引く」に統一 |
| **左ドラッグ** | 始点グループの状態に合わせ、通過グループを連続追加/連続除外（なぞり選択） | 連続ストローク / 範囲 / 囲み塗り | 複数アイランドを1ストロークで一網打尽 |
| **Ctrl + 右ドラッグ** (左右) | — | **ブラシサイズの手元無段階伸縮** | **上部スライダーへのマウス往復を完全消滅** |
| **C キー長押し** | **カーソル直下にラジアルメニュー (Pie Menu) を表示** | 同左 | **ツールバーへの長距離マウス移動をゼロ化** |
| **X キー** | **左右対称 (X-Mirror) の ON/OFF 切替** | 同左 | **両腕・両足のクリック数＆カメラ回転を 50% 削減** |
| **Shift + マウスホイール** | **選択範囲の拡張 (Grow) / 縮小 (Shrink)** | — | 隣接アイランドへ直感的に選択を広げる |
| **Alt / 中ボタンドラッグ** | **Unity標準カメラ操作（完全保護・ツールは入力非消費）** | 同左 | 視点移動で誤って塗ってしまう事故を防止 |
| **Ctrl+Z / Ctrl+Y**（Ctrl+Shift+Z も可） | **統合 Undo / Redo（選択＋手塗りの一体履歴）** | 同左 | 手元で即座にリカバリー |
| **Ctrl+A / Ctrl+I** | 全選択 / 選択の反転 | — | 慣習どおりのキーで説明不要 |
| **Ctrl + Enter** | **クイック出力（現在の設定で即座にPNG出力）** | 同左 | ツールタブへ戻らずキー1つで保存完了 |
| **Tab** | 選択 ⇄ ペイント モード切替 | 同左 | 片手キーボードで瞬時に往復 |
| **1 / 2 / 3** | 選択の単位: 島 / パーツ / 面 | — | 左手だけで粒度変更 |
| **B / M / L / E** | — | ブラシ / 矩形 / 投げ縄 / 消しゴム | ペイントツールの即時切替 |

**選択の単位と既存の選択**
- 選択は三角形単位で保持する。「選択の単位」は次のクリックで扱うまとまりを決めるだけで、切り替えても既存の選択は変わらない（面で細かく選んだ後に島へ切り替えても、面の選択は消えない）。
- 一部だけ選択されているまとまりは未選択として扱い、クリックで全体を追加する（ホバーは白縁）。全体が選択済みの時だけ除外（赤縁）になる。

### 5.2 カーソル直下ラジアルメニュー (Pie Menu) の仕様

`C` キーを押し下げている間、**カーソル直下に直径 180px のリング状メニュー**を出す（Surface1 + Outline）。スライスは**アイコンのみ**で、ポインタが向いているスライスの名前だけを中心に表示する。

位置が固定の 3 方向（↑ モード、↗ 対称、↖ クリア）は両モード共通にし、残りはモードに応じて差し替える。

```
選択モード                          ペイントモード
        [↑ ペイントへ]                       [↑ 選択へ]
 [↖ クリア]       [↗ 対称]          [↖ クリア]       [↗ 対称]
 [← 全選択]  (中心:名前) [→ 島]     [← ─ ]  (中心:名前) [→ ブラシ]
 [↙ 反転]         [↘ パーツ]        [↙ 消しゴム]     [↘ 矩形]
        [↓ 面]                               [↓ 投げ縄]
```

- **フリック決定**: キーを押したままその方向へ 15〜20px 動かし、キーを離すと決定。動かさずに離せば何もしない。
- **現在値**: 選択中の単位・ツールのスライスに青枠（`.dennoko-button-active`）。
- **キー一覧**: 0.6 秒動かさずに押し続けると、各スライスにキーを添えて表示（§2.6.3 段階 4）。
- キーを離すとフェードアウトする。

---

### 5.3 左右対称選択 (X-Mirror) の動作仕様
- 基準面はアバタールート（`Animator` を持つ最上位の祖先）のローカル X=0。見つからない時は Renderer のローカル X=0。対称位置にあるアイランド・三角形を自動ペアリングする。
- 右腕のアイランドをクリックすると、**左腕の対応アイランドにも同じ結果**（追加なら追加、除外なら除外）を適用する。両側の状態が食い違っていても、クリックした側の結果に揃える。
- ホバー中は対応するアイランドも同時に縁取りし、押す前に両側に効くと分かるようにする。自動 ON（§2.5.3）の時も、カプセルの対称ボタンの青枠とこの縁取りで気付ける。
- 対応が見つからないアイランド（体の中心にまたがるものなど）は、そのアイランドだけに適用する。
- ペイントは**シーン上のストロークだけ**を対称位置へ反映する。UV ビュー上のストロークは反映しない（UV 配置が左右対称とは限らないため）。

常設のヒント行は置かない。案内はツールチップ、修飾キーのバッジ、迷い検知ヒント、ラジアルのキー一覧の 4 段階だけ（§2.6.3）。

## 6. ③ シーン上フローティングUI（SceneView Overlay）

Unity の `Overlay` API で実装。SceneView内に自然に馴染む半透明ダークデザイン（`.dennoko-root` + `.dennoko-card`）。

### 6.1 手元カプセルツールバー（シーン内どこでも移動・固定可能）

横型カプセル（高さ 32px）。ボタンは**アイコンのみ**で、名前とキーはツールチップに出す。画面端にドッキングも、アバターの足元付近に浮かせることもできる。

```
選択モード:
┌───────────────────────────────────────────────────────────────────────────┐
│ [pickable|Paint] │ [島|パーツ|面] │ [対称] │ [visible|hidden] │ [Pause] │ [back|forward|Trash] │ [SaveAs]  12/480 │
└───────────────────────────────────────────────────────────────────────────┘
ペイントモード（2 番目のセグメントだけが差し替わる）:
│ [pickable|Paint] │ [Paint|Rect|EditCollider|Eraser] 50px │ [対称] │ ... │ [SaveAs] │
```

1. **モードと選択の単位 / ペイントツール**: 現在値に青枠（`.dennoko-button-active`）。同じ位置をモードで差し替える。
2. **対称・X-Ray・孤立表示・一時停止**: トグル。ON の時は青枠。値はセッション内のみで、初期値は Preferences のユーザー既定。
3. **出力**: 押すと即時出力。成功時は 2 秒間ボタンの枠を `--dennoko-semantic-success` にする（アイコンは差し替えない）。
4. **選択数**: 右端の `12/480` が唯一の常設の数値。ペイントモードではブラシサイズ（`50px`）をツール群の横に出す。

---

### 6.2 出力完了トースト＆スマート適用 (Smart Apply)

出力した直後、**カーソルのすぐ脇にトースト**を 1 行で出す。

```
┌──────────────────────────────────────────┐
│ [SaveAs] Body_mask.png      [Material 適用] │
└──────────────────────────────────────────┘
```

- ファイル名をクリックで Ping、ダブルクリックでフォルダを開く（ボタンを増やさない）。
- 4 秒で消える。ホバー中は消えない。

- **「適用」ボタン**:
  - 適用先は `TargetSubmesh` のマテリアル（全体を対象にしている時は、対象 Renderer の先頭マテリアル）。シェーダー（lilToon, Poiyomi, UTS2, Standard 等）のテクスチャプロパティを解析する。
  - **適用先スロットは初回だけ選ぶ**: マスクの用途（影・発光・2nd カラーなど）はシェーダー側からは決められないため、自動では決め打ちしない。候補が 1 つなら即適用。複数ある時は [適用] の位置に候補リスト（マスク用の名前を上位に並べる。例: lilToon の `_MainColor2ndBlendMask`、Poiyomi の `_DecalMask`）を出し、選んだ時点で適用する。選んだスロットは Target ごとに記憶し、2 回目以降は 1 クリック。
  - 候補が無いシェーダーでは [適用] を出さない（押せないボタンを置かない）。
  - 再出力で同じファイルが既にスロットに入っている時は [適用] を出さず、トーストは `更新: Body_mask.png` だけにする（上書きなので割り当て直し不要）。
  - 適用も作業履歴に 1 件として積み、直後の Ctrl+Z で取り消せる（作業履歴そのものを Unity の Undo に載せているので、選択・手塗り・適用が 1 本の履歴になる）。
  - **効果**: 「Projectビューからファイルを探してマテリアルのInspectorにドラッグ＆ドロップする」手作業が、初回は 2 クリック、以後は 1 クリック（再出力時は 0 クリック）になる。

## 11. 実装メモ

- **ラジアルメニュー (Pie Menu)**:
  - `SceneView.duringSceneGui` または SceneViewのオーバーレイルート直下に UI Toolkit `VisualElement` を絶対座標配置。
  - `C` キーの `KeyDown` でマウス位置（`Event.current.mousePosition`）を中心に表示、`KeyUp` で選択確定＆非表示。
- **左右対称判定ロジック**:
  - 解析時に三角形ごとの対称相手（`MirrorTri`）を空間ハッシュで求め、グループの対応は投票で決める（`Docs/Impl/mesh_analysis.md` §8、`selection_system.md` §4.5）。
- **マテリアル自動適用**:
  - ターゲットRendererの `sharedMaterials` を走査し、主要シェーダー（lilToon, Poiyomi, UTS2, Standard等）のプロパティ名リスト（`_MaskTex`, `_DecalMask`, `_MainTex` 等）を照合して即時割り当て＋Undo登録。
- **UV 展開図ラスタライザ (UV Layout Exporter)**:
  - 指定解像度（既定 2048）の `Texture2D`（RGBA32）に、CPU または `Graphics.DrawProcedural` / `GL.LINES` で UV 座標の三角形エッジ・シームエッジを描画。
  - 色分け ON 時は、各アイランドの三角形をハッシュ由来のパステルカラーで充填ラスタライズした上にエッジを描画。
  - 背景は透過（Alpha=0）またはベーステクスチャの `Graphics.Blit`。PNG 圧縮して `{FileName}_uv.png` に保存。
- **入力競合保護**:
  - `HandleUtility.AddDefaultControl` を適切に使用する。右ボタンドラッグは Ctrl 押下中だけ本ツールが消費し（ブラシ伸縮）、それ以外の右ドラッグ（フライスルー）・Alt・中ボタンは Unity 標準カメラ操作を 100% 優先する。
- **作業ツール**:
  - 作業中は独自の `EditorTool` をアクティブにし、そのツールが有効な間だけショートカットのタグを登録する。Unity の他ツールへ切り替わったら一時停止扱いにする（§2.6.7）。
  - 作業中は `EventType.MouseEnterWindow` で SceneView に `Focus()` を移し、キーがマウス位置のビューに届くようにする。
- **作業状態の保存と復元**:
  - 選択は三角形インデックスのビット列、手塗りは連長圧縮して `UserSettings/UVMaskMaker/targets/{TargetKey}/session.bin` に保存する。メッシュハッシュ（頂点数・サブメッシュ数・インデックス）で一致を確認し、不一致なら復元しない（`Docs/Impl/mask_processing.md` §3.5）。
  - 保存は終了・対象切替・出力の時と、変更後数秒の遅延で行う（クラッシュとドメインリロード対策）。
  - 自動終了は `EditorApplication.playModeStateChanged`、`EditorSceneManager.sceneClosing`、`AssemblyReloadEvents.beforeAssemblyReload` で拾う。
- **上書き出力**:
  - Target ごとに前回の出力パスを記録し、同じファイル名ならそのパスへ上書きする。連番の解決（元/反転ペア）は、記録パス以外と衝突した時だけ行う。
- **設定の階層と永続化**（§2.5.4）:
  - 値の解決順は `Session > Target > Project > User > 組み込み既定`。各層は `MaskSettings` の差分（上書き値のみ）を保持し、未設定の項目は上位層へフォールバック。
  - 保存先: User=`EditorPrefs`、Project=`ProjectSettings/UVMaskMaker.json`、Target=`UserSettings/UVMaskMaker/targets/{TargetKey}/settings.json`、Session=メモリのみ。
  - 変更は全てイベント通知し、①と③は同じ解決済みの値を購読する。
  - ホットキーは `[Shortcut]` 属性で Unity の Shortcut Manager に登録し、再割当ては標準 UI に任せる。
- **アイコン確認**:
  - §2.6.6 の名前を `EditorGUIUtility.FindTexture` で引き、null のものを Console に列挙するメニューを用意する。Unity 2022.3 / Unity 6 の両方で実行してから確定する。
- **ショートカット**:
  - 全キーを `[Shortcut(id, typeof(SceneView), "UVMaskMaker.Working", key)]` で登録し、作業中かつ作業ツールが有効な間だけ `ShortcutManager.RegisterTag("UVMaskMaker.Working")` する（`IShortcutToolContext` は 2022.3 では internal のため使えない）。C と Space は `[ClutchShortcut]`。Undo / Redo は Unity 標準。
- **迷い検知ヒント**:
  - ヒントごとに表示回数を `EditorPrefs` に保存し、3 回で以後出さない。同時に出すヒントは 1 件。
- **テーマ検証**:
  - Personal Light/Dark の双方で文字・枠線・トーストの視認性を担保。`DennokoUIFont.Apply` を徹底。
